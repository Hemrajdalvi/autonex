# Autonex 🚀
**The AI that really does things — Complete Autonomous Execution, Local AI & Multi-Agent Swarm Platform**

Autonex ek next-generation autonomous AI platform hai jo user ko sirf chat responses nahi, balki end-to-end complete kiya hua kaam deta hai.

## Core Capabilities

### 1. OS & Computer Control 🖥️
AI user ke computer par khud kaam karega.
- **Mouse & Keyboard Control:** Screen elements ko pehchan kar direct clicks, typing, aur shortcuts execute karna.
- **Files & Folders Management:** Local files organize karna, rename karna, search karna aur directories manage karna.
- **Excel to Invoice & PDF Automation:** Excel sheets ke data ko read karke automatically formatted invoices aur PDF reports generate karna.
- **Browser Task Automation:** Web browser mein repetitive forms, data entry, aur multi-page workflows ko automate karna.
- **Multi-Step Execution:** Ek single instruction mein kai steps wale complex workflows ko bina ruke complete karna.
- **Goal:** User ko sirf jawab nahi, balki complete kiya hua kaam dena.

### 2. Offline Local AI 🧠
AI ko local models ke saath chalane ki capability.
- **Local AI Models Support:** Ollama, llama.cpp, aur GGUF quantized models ke sath direct local execution.
- **Zero Cloud API Dependency:** Supported tasks ko bina kisi external Cloud API ke locally run karna.
- **8 GB RAM Lightweight Mode:** Standard 8 GB RAM wale laptops ke liye optimized memory footprint aur quantized model profile.
- **Dynamic Hybrid Switching:** Task ki complexity aur internet availability ke hisaab se cloud aur local models ke beech automatic switching.
- **Goal:** API costs kam karna aur sensitive data ko local rakhne ka option dena.
> **Note:** Dhyan rahe, har task 8 GB RAM par ya bina internet ke chal paayega, iski guarantee nahi hai. Heavy reasoning ya live web tasks ke liye hybrid cloud fallback use hota hai.

### 3. Agent-to-Agent Swarm 🤖
AI doosre AI agents ke saath milkar kaam karega.
- **Task Decomposition:** Complex projects ko chhote, manageable sub-tasks mein divide karna.
- **Parallel Multi-Agent Research:** Ek sath multiple specialized agents ko deploy karke tezi se deep research karwana.
- **Supplier Price Comparison:** Alag-alag vendors aur suppliers ke prices aur terms ko compare karke best option nikalna.
- **Business Workflow Automation:** End-to-end business operations, reporting, aur follow-ups ko automate karna.
- **Bounded Negotiation:** User dwara set kiye gaye spending limits aur approval rules ke andar rehkar autonomous negotiation karna.
- **Goal:** Ek AI assistant ko multi-agent automation platform mein badalna.

## Architecture & Quick Start
- **Desktop & OS Layer:** Native OS hooks (Mouse/Keyboard/Filesystem/Excel-to-PDF engine)
- **Inference Router:** Local LLM Runtime (8 GB RAM Lightweight Mode) + Cloud API Hybrid Switcher
- **Swarm Orchestrator:** Multi-Agent Planner, Parallel Research Workers, & Approval Guardrails
